# Задание 10. Строгий `DateTimeFormatter`

## Условие

Парсите даты формата `dd.MM.uuuu`, отклоняя невозможные даты и лишний текст. Сообщение ошибки содержит поле и исходное значение, но не скрывает cause без причины.

## Где код

- `DateParser.java`
- `InvalidDateFieldException.java`
- тесты: `DateParserTest.java`

## Решение

- `DateTimeFormatter.ofPattern("dd.MM.uuuu").withResolverStyle(ResolverStyle.STRICT)`.
- Используется `uuuu` (год), а не `yyyy` (год эры): в `STRICT` режиме `yyyy` без указания эры не разрешается в дату.
- `LocalDate.parse(text, formatter)` требует разобрать весь текст, поэтому хвост (`17.10.2026abc`, `17.10.2026 12:00`, пробел в конце) приводит к ошибке.
- `STRICT` отклоняет несуществующие даты: `31.04.2026`, `29.02.2025`, `29.02.2100`.

## Таблица

| Значение | Результат |
|---|---|
| `17.10.2026` | валидно |
| `29.02.2024`, `29.02.2000` | валидно (високосные годы) |
| `29.02.2025`, `29.02.2100` | ошибка, год не високосный |
| `31.04.2026` | ошибка, в апреле нет 31 числа |
| `32.01.2026`, `00.01.2026`, `15.13.2026` | ошибка, значение вне диапазона |
| `17.10.2026 `, ` 17.10.2026` | ошибка, лишний пробел |
| `17.10.2026abc`, `17.10.2026 12:00` | ошибка, лишний текст |
| `1.1.2026` | ошибка, нужны две цифры |
| `17.10.26` | ошибка, нужен четырёхзначный год |
| `17.10.12345` | ошибка, пять цифр года без знака |
| `2026-10-17`, `17/10/2026` | ошибка, другой формат |
| арабско-индийские цифры | ошибка, только ASCII-цифры |
| `null` | ошибка «value is required» |

## Исключение

`InvalidDateFieldException` наследует `IllegalArgumentException` и хранит `fieldName` и `rawValue`.

Пример сообщения:

```
Invalid date in field 'startDate': "31.04.2026" (Text '31.04.2026' could not be parsed: Invalid date 'APRIL 31')
```

- Если ошибку выбросил парсер, исходный `DateTimeParseException` передаётся как `cause`, и текст его сообщения попадает в итоговое сообщение.
- Если значения нет (`null`), парсер ничего не бросал, поэтому причины нет, `getCause()` равен `null` и в сообщении сказано `value is required`. Здесь причина не скрывается — её просто не существует.
