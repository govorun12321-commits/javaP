# Задание 13. Нормализованный поиск
Создайте pipeline нормализации названий: strip, схлопывание пробелов, case folding по фиксированной locale. Отделите display value от search key и покажите конфликт двух разных исходных строк.

- `CourseTitle.java`
- тесты: `CourseTitleTest.java`

## Pipeline

| Шаг | Display value | Search key |
|---|---|---|
| Unicode-нормализация NFKC | нет | да |
| `strip()` | да | да |
| схлопывание любых Unicode-пробелов в один пробел (`\s+` с `UNICODE_CHARACTER_CLASS`), повторный `strip()` | да | да |
| case folding: `toUpperCase(Locale.ROOT).toLowerCase(Locale.ROOT)` | нет | да |

- **Display value** — то, что показываем пользователю: очищенный от лишних пробелов текст с исходным регистром.
- **Search key** — то, по чему ищем и сравниваем. Запрос пользователя проходит через ту же функцию `CourseTitle.searchKey(query)`.
- Фиксированная `Locale.ROOT` защищает от зависимости от локали сервера (в турецкой locale `"TITLE".toLowerCase()` дал бы `tıtle`). Тест выставляет `tr-TR` и проверяет, что ключ не меняется.
- В Java нет полноценного case folding, поэтому используется приближение «в верхний, затем в нижний регистр»: так `ß` и `SS` сходятся в `ss`.
- NFKC приводит к одному виду составные и разложенные буквы (`é` и `e` + U+0301) и полноширинные символы.
