# Задание 14. `Money` и цена курса

Спроектируйте неизменяемый `Money` с amount и currency, запретом смешения валют, явным округлением и содержательным равенством. Реализуйте add, subtract, percentage и allocation без double.

- `Money.java`
- тесты: `MoneyTest.java`

## Операции

- `add`, `subtract`, `negate` — точная арифметика.
- `percentage(percent, mode)` — сумма умножается на процент и сдвигается на два знака, округление выполняется один раз: `19.99 EUR × 10 %` даёт `2.00` для `HALF_UP` и `UP`, `1.99` для `DOWN`.
- `allocate(ratios)` — распределение по весам в минимальных единицах: каждая доля считается целочисленным делением, остаток раздаётся по одной минимальной единице с начала списка (части с нулевым весом пропускаются). Сумма долей всегда равна исходной сумме.
  - `100.00 EUR` на `[1, 1, 1]` → `33.34, 33.33, 33.33`;
  - `0.05 EUR` на `[3, 7]` → `0.02, 0.03`;
  - `100 JPY` на три части → `34, 33, 33`;
  - работает и для отрицательных сумм.
- `split(parts)` — равное распределение, частный случай `allocate`.
