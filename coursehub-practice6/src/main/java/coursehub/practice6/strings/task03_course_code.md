# Задание 3. Регулярное выражение с группами

## Условие

Проверьте код курса вида `JAVA-101`, извлеките prefix и number, запретите частичное совпадение. Подготовьте таблицу валидных и невалидных значений, включая Unicode и пробелы.

## Где код

- `CourseCode.java`
- тесты: `CourseCodeTest.java` (в нём те же таблицы значений)

## Решение

```
(?<prefix>[A-Z]{2,5})-(?<number>[0-9]{3})
```

- Именованные группы `prefix` и `number` дают извлечение частей.
- Используется `Matcher.matches()`, а не `find()`: совпадать должна вся строка. `matches()` также не принимает завершающий `\n`, в отличие от `$` при поиске.
- Классы символов явные (`[A-Z]`, `[0-9]`), поэтому юникодные буквы и цифры не проходят.
- Префикс — от 2 до 5 латинских заглавных букв, номер — ровно три цифры. `number` хранится как `int`, текст восстанавливается через `String.format(Locale.ROOT, "%s-%03d", ...)`, чтобы лидирующие нули не терялись и формат не зависел от locale.

## Таблица значений

| Значение | Результат | Причина |
|---|---|---|
| `JAVA-101` | валидно | основной случай |
| `SQL-001` | валидно | лидирующие нули допустимы |
| `GO-999` | валидно | минимум 2 буквы |
| `KOTLN-250` | валидно | максимум 5 букв |
| `java-101`, `Java-101` | невалидно | нижний регистр |
| `JAVA101` | невалидно | нет дефиса |
| `JAVA-10`, `JAVA-1010` | невалидно | не три цифры |
| `J-101` | невалидно | префикс короче 2 |
| `JAVAXX-101` | невалидно | префикс длиннее 5 |
| ` JAVA-101`, `JAVA-101 ` | невалидно | пробел по краям |
| `JAVA-101\n` | невалидно | завершающий перевод строки |
| `JAVA -101`, `JAVA- 101` | невалидно | пробел внутри |
| `JAVA-101-X`, `XX JAVA-101` | невалидно | частичное совпадение |
| `JAVA–101` (U+2013) | невалидно | en dash вместо дефиса |
| `JAVA_101` | невалидно | другой разделитель |
| `ЈAVA-101` (U+0408, кириллическая Ј) | невалидно | похожая на латиницу буква |
| `JAVA-١٠١` (арабско-индийские цифры) | невалидно | не ASCII-цифры |
| `ＪＡＶＡ-101` (полноширинные буквы) | невалидно | не ASCII-буквы |
| `\u00A0JAVA-101` | невалидно | неразрывный пробел |
| `JAVA-101\u200B` | невалидно | невидимый символ нулевой ширины |
| пустая строка, `" "` | невалидно | пусто |
| `null` | невалидно | `tryParse` возвращает `Optional.empty()`, `parse` бросает `IllegalArgumentException` |
