# Задание 7. `Math` и воспроизводимая случайность

## Условие

Сгенерируйте учебную выборку через `RandomGenerator` с seed, вычислите границы и округление. Разделите production randomness и детерминированный тестовый источник.

## Где код

- `RandomSampleService.java`
- `SampleStats.java`
- тесты: `RandomSampleServiceTest.java`, `SampleStatsTest.java`

## Разделение источников случайности

- `RandomSampleService` получает `RandomGenerator` через конструктор и ничего не знает о том, откуда он взялся.
- `production()` создаёт сервис на `SecureRandom` — непредсказуемый источник для реальной работы.
- `seeded(seed)` создаёт сервис на `L64X128MixRandom` с фиксированным seed — для тестов, демонстраций и воспроизведения экспериментов.
- Тесты могут подставить любой генератор, например `new Random(5)`.

Вывод `RandomSampleService.main` для `seed = 42`, 10 значений в диапазоне `[0, 101)`:

```
[98, 62, 46, 20, 57, 76, 57, 75, 6, 17]
```

Два запуска с одним seed дают одинаковый список. Тесты проверяют именно воспроизводимость и границы, а не конкретные числа.

## Границы и округление (`SampleStats`)

| Операция | Что демонстрирует |
|---|---|
| `Math.min`, `Math.max` | границы выборки |
| `Math.addExact` | сумма в `long` без молчаливого переполнения |
| `Math.floor`, `Math.ceil`, `Math.round` | три способа округления среднего (для 51,4: 51, 52, 51) |
| `Math.clamp(value, min, max)` | ограничение значения границами выборки |
| `Math.floorDiv`, `Math.floorMod` | корректные номера корзин и позиция в корзине для отрицательных чисел |
| `Math.multiplyExact` | начало корзины без переполнения |

Нюансы:

- `Math.round` округляет половины к `+∞`: `round(2.5) = 3`, `round(-2.5) = -2`.
- `-1 / 10 = 0`, но `Math.floorDiv(-1, 10) = -1`; `-1 % 10 = -1`, но `Math.floorMod(-1, 10) = 9`. Поэтому для корзин используется `floorDiv` и `floorMod`.
- Для выборки из примера: `mean = 51.4`, `median = 57.0`, `roundedMean = 51`.
